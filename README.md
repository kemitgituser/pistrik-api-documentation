# pistrik-api-documentation
Estonian waste information system (PISTRIK) REST API documentation

* Documentation regarding API integration possibilities is located in this repo under [WIKI](https://github.com/kemitgituser/pistrik-api-documentation/wiki)
* Documentation regarding specific API calls and example requests with responses can be found in public `Postman workspace`: [PISTRIK PUBLIC](https://www.postman.com/pistrik/pistrik-public/)
* Source files of collections and environments exported from `Postman workspace` can be found in folders:
  * /postman/collections
  * /postman/environments
